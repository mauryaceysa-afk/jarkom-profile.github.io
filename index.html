Poster STBI

Halaman ini menampilkan poster karya Kelompok Jaringan Komputer 1 yang berjudul "Mystery Behind the Website". Poster ini mengupas tuntas berbagai proses teknis dan komponen yang bekerja di balik layar setiap kali kita membuka sebuah situs web di internet.
Melalui visualisasi poster ini, Anda dapat mempelajari:

  • Konsep Dasar Website : Pengertian website, domain, hosting/server, dan browser.
  • Komponen Utama : Peran HTML, CSS, JavaScript, server, dan database.
  • Jenis Website : Perbedaan antara website statis dan dinamis.
  • Alur Kerja Teknis : Proses akses mulai dari Browser → DNS → Server → Data → Rendering → Website.
  • Fakta Unik : Sejarah singkat penciptaan World Wide Web oleh Tim Berners-Lee hingga fakta kecepatan akses dalam hitungan milidetik.

Arti nama kami

Secara etimologi, kata "Jaringan" berasal dari kata dasar jaring (sistem terhubung yang saling mengikat), sedangkan "Komputer" berasal dari bahasa Latin computare yang berarti menghitung atau mengolah informasi. Dalam dunia teknologi, Jaringan Komputer merujuk pada sistem yang menghubungkan dua atau lebih perangkat komputer untuk saling berkomunikasi, berbagi data, dan mengelola sumber daya bersama.
